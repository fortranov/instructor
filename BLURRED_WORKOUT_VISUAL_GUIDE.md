# Визуальное руководство: Замыленные карточки тренировок

## Сравнение карточек

### Доступная тренировка ✅

```
┌──────────────────────────────────┐
│  🏃 ●                 [≡] [✓]   │  ← Иконка спорта + кнопки управления
│                                  │
│  45 минут                        │  ← Четкий текст
│                                  │
│  Интервальная                    │  ← Цветной бейдж типа тренировки
└──────────────────────────────────┘
```

**Характеристики:**
- Opacity: 1.0 (100%)
- Filter: none
- Background: белый или зеленый (если выполнена)
- Border: четкий
- Интерактивность: ✅ Полная

---

### Недоступная тренировка (замыленная) 🔒

```
┌──────────────────────────────────┐
│           🔒                      │  ← Иконка замка по центру
│      ╔═══════════════╗           │
│      ║  🏃 ●         ║           │  ← Размытое содержимое
│      ║               ║           │
│      ║  45 минут     ║           │  ← Размытый текст
│      ║               ║           │
│      ║ Интервальная  ║           │  ← Размытый бейдж
│      ╚═══════════════╝           │
└──────────────────────────────────┘
```

**Характеристики:**
- Opacity: 0.5 (50%)
- Filter: blur(2px)
- Background: светло-серый (#f9fafb)
- Border: тусклый (#e5e7eb)
- Интерактивность: ❌ Отключена
- Иконка замка: четкая (не размыта)

## CSS эффекты

### Доступная карточка

```css
.workout-card-accessible {
  opacity: 1;
  filter: none;
  background-color: #ffffff;
  border-color: #e5e7eb;
  cursor: pointer;
  pointer-events: auto;
  transition: all 0.2s;
}

.workout-card-accessible:hover {
  box-shadow: 0 4px 6px rgba(0, 0, 0, 0.1);
}
```

### Замыленная карточка

```css
.workout-card-blurred {
  opacity: 0.5;
  filter: blur(2px);
  background-color: #f9fafb;
  border-color: #e5e7eb;
  cursor: not-allowed;
  pointer-events: none;
  user-select: none;
  position: relative;
}

.workout-card-blurred::before {
  content: '🔒';
  position: absolute;
  inset: 0;
  display: flex;
  align-items: center;
  justify-content: center;
  background-color: rgba(17, 24, 39, 0.05);
  filter: blur(0);
  font-size: 1rem;
  z-index: 10;
}
```

## Детальный вид карточек

### Обычная карточка (детально)

```
┌─────────────────────────────────────────────────┐
│ 🏃 ●                         [≡≡≡] [✓]         │ ← Верхний ряд
│                                                 │
│ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━       │
│                                                 │
│ 45 минут                                        │ ← Продолжительность
│                                                 │
│ ┌─────────────────────┐                        │
│ │  Интервальная      │                        │ ← Тип тренировки
│ └─────────────────────┘                        │
│                                                 │
└─────────────────────────────────────────────────┘

Элементы:
- 🏃 = Иконка вида спорта
- ● = Цветовая метка вида спорта
- [≡≡≡] = Кнопка перемещения (drag)
- [✓] = Кнопка отметки выполнения
```

### Замыленная карточка (детально)

```
┌─────────────────────────────────────────────────┐
│             ┌───────────┐                        │
│             │           │                        │
│             │    🔒     │                        │ ← Замок (четкий)
│             │           │                        │
│             └───────────┘                        │
│                                                 │
│        ╔═══════════════════════════╗           │
│        ║ ░░░░░░░░░░░░░░░░░░░░░░░░ ║           │ ← Размытый контент
│        ║ ░░░░ 45 минут ░░░░░░░░░░ ║           │
│        ║ ░░░░░░░░░░░░░░░░░░░░░░░░ ║           │
│        ║ ░░ Интервальная ░░░░░░░░ ║           │
│        ╚═══════════════════════════╝           │
└─────────────────────────────────────────────────┘

Характеристики:
- Весь контент размыт (blur 2px)
- Полупрозрачный (opacity 0.5)
- Замок четкий и по центру
- Серый фон
- Нет кнопок управления
```

## Поведение при взаимодействии

### Доступная тренировка

| Действие | Результат |
|----------|-----------|
| Клик | Открывается модальное окно с деталями |
| Наведение | Появляется тень, меняется курсор |
| Drag | Можно перетащить в пределах недели |
| Кнопка ✓ | Отмечается как выполненная |

### Замыленная тренировка

| Действие | Результат |
|----------|-----------|
| Клик | Ничего (pointer-events: none) |
| Наведение | Курсор "not-allowed" |
| Drag | Невозможно (disabled) |
| Кнопка ✓ | Отсутствует |

## Адаптивность

### Desktop (> 1024px)
- Карточки: стандартный размер
- Blur: 2px
- Замок: 16x16px

### Tablet (768-1024px)
- Карточки: немного меньше
- Blur: 2px
- Замок: 16x16px

### Mobile (< 768px)
- Карточки: компактные
- Blur: 2px (может быть увеличен до 3px)
- Замок: 14x14px

### Плавное появление

```css
@keyframes fadeIn {
  from {
    opacity: 0;
    transform: translateY(10px);
  }
  to {
    opacity: 0.5;
    transform: translateY(0);
  }
}

.workout-card-blurred {
  animation: fadeIn 0.3s ease-out;
}
```

## Accessibility

### ARIA атрибуты

Доступная карточка:
```html
<div 
  role="button"
  aria-label="Тренировка: Бег, Интервальная, 45 минут"
  tabindex="0"
>
```

Замыленная карточка:
```html
<div 
  role="presentation"
  aria-label="Недоступная тренировка. Обновите тариф для доступа."
  aria-disabled="true"
>
```
