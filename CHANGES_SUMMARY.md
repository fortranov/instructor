## 🔄 Как это работает

1. Пользователь регистрируется через API endpoint `/api/v1/auth/register`
2. Вызывается функция `create_user()` из модуля `auth`
3. Функция автоматически находит тестовый тариф в базе данных
4. Пользователю присваивается `tariff_id` тестового тарифа
5. Пользователь может использовать возможности тестового тарифа сразу после регистрации
