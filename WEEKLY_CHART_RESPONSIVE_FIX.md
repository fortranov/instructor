# Исправление: Адаптивная диаграмма без горизонтального скролла

## Проблема
На странице статистики диаграмма недельных объемов тренировок имела горизонтальный скролл, что было неудобно для просмотра.

## Решение

### Внесенные изменения в `frontend/src/components/yearly-chart.tsx`:

#### 1. Убран горизонтальный скролл
**Было:**
```tsx
<div className="flex gap-1 h-64 items-end overflow-x-auto">
```

**Стало:**
```tsx
<div className="flex gap-0.5 h-64 items-end">
```

- Убран класс `overflow-x-auto`
- Уменьшен gap с `gap-1` (4px) до `gap-0.5` (2px) для более компактного размещения

#### 2. Адаптивная ширина столбцов
**Было:**
```tsx
<div style={{ width: '20px' }} className="flex flex-col items-center flex-shrink-0 relative">
```

**Стало:**
```tsx
<div className="flex flex-col items-center flex-1 relative min-w-0">
```

- Убрана фиксированная ширина `20px`
- Добавлен класс `flex-1` - столбцы равномерно заполняют доступное пространство
- Добавлен класс `min-w-0` - предотвращает переполнение flex-элементов
- Убран класс `flex-shrink-0` - теперь столбцы могут сжиматься

#### 3. Адаптивная ширина подписей месяцев
**Было:**
```tsx
<div 
  className="flex-shrink-0 text-center"
  style={{ width: `${weeks.length * 21}px` }}
>
```

**Стало:**
```tsx
<div 
  className="text-center"
  style={{ width: `${monthWidthPercent}%` }}
>
```

Где `monthWidthPercent` рассчитывается как:
```tsx
const totalWeeks = displayData.length;
const monthWidthPercent = (weeks.length / totalWeeks) * 100;
```

- Ширина каждого месяца теперь пропорциональна количеству недель в нем
- Используются проценты вместо фиксированных пикселей

#### 4. Удалена синхронизация скролла
Так как скролл больше не нужен, удалены:
- Импорт `useRef` и `useEffect`
- Refs: `chartRef` и `monthsRef`
- Обработчик `handleChartScroll`
- Атрибуты `ref` и `onScroll` из контейнеров

## Результат

### До изменений:
- ✗ Фиксированная ширина столбцов 20px
- ✗ Горизонтальный скролл для просмотра всех недель
- ✗ Подписи месяцев не синхронизировались со столбцами
- ✗ Неудобный просмотр на разных размерах экранов

### После изменений:
- ✅ Адаптивная ширина столбцов
- ✅ Все недели видны без скролла
- ✅ Подписи месяцев автоматически выравниваются со столбцами
- ✅ Диаграмма адаптируется под любую ширину экрана
- ✅ Более компактное отображение данных

## Поведение на разных экранах

### Широкие экраны (desktop, >1024px)
- Столбцы шире, легко различимы
- Комфортный просмотр всех 52 недель года

### Средние экраны (tablet, 768-1024px)
- Столбцы средней ширины
- Все данные видны без скролла

### Узкие экраны (mobile, <768px)
- Столбцы более узкие, но все еще различимы
- Все недели умещаются на экране
- Можно увеличить масштаб для детального просмотра

## Технические детали

### Расчет ширины
Каждый столбец занимает равную долю доступного пространства:
```
Ширина столбца = (100% - gaps) / количество_недель
```

Для года с 52 неделями и gap 0.5 (2px):
- На экране 1200px: каждый столбец ~22px
- На экране 800px: каждый столбец ~15px
- На экране 400px: каждый столбец ~7px

### Gap между столбцами
Уменьшен с `gap-1` (4px) до `gap-0.5` (2px):
- Более компактное размещение
- Меньше потери пространства
- Столбцы остаются различимыми

## Примечания

Класс `.hide-scrollbar` в `globals.css` сохранен для возможного использования в будущем, но больше не применяется к этому компоненту.
