# Ограничение видимости тренировок по тарифам

## Описание функционала

Реализована система отображения тренировок в зависимости от тарифного плана пользователя. Недоступные тренировки отображаются в "замыленном" виде с иконкой замка.

## Правила видимости тренировок

### 🔓 Тестовый тариф (`test`)
- **Доступ:** Только 2 недели от текущей даты
- **Описание:** Пользователь видит тренировки на ближайшие 14 дней
- **Остальные тренировки:** Замыленные

### 🔓 Пробный тариф (`trial`)
- **Доступ:** Текущая неделя + 2 недели вперед (всего 3 недели / 21 день)
- **Описание:** Пользователь видит тренировки на ближайшие 21 день
- **Остальные тренировки:** Замыленные, но видимые

### 🔓 Про тариф (`pro`)
- **Доступ:** Полный доступ ко всем тренировкам
- **Описание:** Пользователь видит весь план до конца
- **Ограничений нет**

#### 2. Обновлен `frontend/src/components/calendar.tsx`

**Добавлены:**
- Импорт `UserTariffResponse` и `BlurredWorkoutCard`
- Проп `userTariff?: UserTariffResponse | null`
- Функция `isWorkoutAccessible(workoutDate: string): boolean`

**Логика проверки доступности:**
```typescript
const isWorkoutAccessible = (workoutDate: string): boolean => {
  const today = new Date();
  const workout = new Date(workoutDate);

  // Pro - все доступно
  if (userTariff.tariff_type === 'pro') return true;

  // Test - 2 недели
  if (userTariff.tariff_type === 'test') {
    const twoWeeks = new Date(today);
    twoWeeks.setDate(twoWeeks.getDate() + 14);
    return workout <= twoWeeks;
  }

  // Trial - 3 недели
  if (userTariff.tariff_type === 'trial') {
    const threeWeeks = new Date(today);
    threeWeeks.setDate(threeWeeks.getDate() + 21);
    return workout <= threeWeeks;
  }

  return true;
};
```

**Рендеринг карточек:**
```typescript
{dayWorkouts.map((workout, workoutIndex) => {
  const isAccessible = isWorkoutAccessible(workout.date);
  
  if (!isAccessible) {
    return <BlurredWorkoutCard key={workoutIndex} workout={workout} />;
  }
  
  return <DraggableWorkout ... />;
})}
```

#### 3. Обновлен `frontend/src/app/plan/page.tsx`

**Добавлено:**
- Импорт `UserTariffResponse`
- State: `const [userTariff, setUserTariff] = useState<UserTariffResponse | null>(null)`
- useEffect для загрузки тарифа пользователя
- Передача `userTariff` в компонент `Calendar`

```typescript
// Загрузка тарифа пользователя
useEffect(() => {
  const loadUserTariff = async () => {
    if (!user) return;
    
    try {
      const tariff = await apiClient.getUserTariff();
      setUserTariff(tariff);
    } catch (err) {
      console.log('Ошибка загрузки тарифа:', getErrorMessage(err));
    }
  };

  if (user) {
    loadUserTariff();
  }
}, [user]);
```

## Поведение

### Недоступные тренировки:
- ❌ Нельзя кликнуть
- ❌ Нельзя перетащить
- ❌ Нельзя отметить как выполненную
- ✅ Видны на календаре (для понимания структуры плана)
- ✅ Видна базовая информация (вид спорта, длительность, тип)

### Доступные тренировки:
- ✅ Можно кликнуть для просмотра деталей
- ✅ Можно перетащить в пределах недели
- ✅ Можно отметить как выполненную
- ✅ Полностью интерактивны

## Преимущества реализации

✅ **Понятность:** Пользователь видит, что план есть, но доступ ограничен  
✅ **Мотивация:** Видимые, но недоступные тренировки мотивируют к апгрейду  
✅ **UX:** Сохранена структура календаря без "дырок"  
✅ **Безопасность:** Детальная информация недоступна, но структура видна  
✅ **Производительность:** Все тренировки загружаются, фильтрация на клиенте
