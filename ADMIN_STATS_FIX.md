# Исправление загрузки статистики на странице администрирования

## Описание проблемы

На странице администрирования `/admin` не подгружалось количество пользователей, хотя на странице "Пользователи" все работало нормально. Статистика показывала нулевые значения.

## Причина проблемы

В файле `frontend/src/app/admin/page.tsx` в функции `fetchStats()` использовалась заглушка с нулевыми значениями вместо реального API запроса:

```typescript
// Старый код - заглушка
setStats({
  totalUsers: 0,
  activeUsers: 0,
  totalPlans: 0
});
```

## Решение

### 1. Добавлен импорт API клиента
```typescript
import apiClient from '@/lib/api';
```

### 2. Обновлена функция загрузки статистики
Заменена заглушка на реальный API запрос:

```typescript
const fetchStats = async () => {
  try {
    // Загружаем данные пользователей для получения статистики
    const users = await apiClient.getAdminUsers();
    
    // Подсчитываем статистику
    const totalUsers = users.length;
    const activeUsers = users.filter(user => user.is_active).length;
    
    // Для подсчета планов можно использовать другой API endpoint
    // Пока используем заглушку для планов
    const totalPlans = 0; // TODO: добавить API для получения количества планов
    
    setStats({
      totalUsers,
      activeUsers,
      totalPlans
    });
  } catch (error) {
    console.error('Ошибка загрузки статистики:', error);
    // В случае ошибки показываем нули
    setStats({
      totalUsers: 0,
      activeUsers: 0,
      totalPlans: 0
    });
  } finally {
    setIsLoading(false);
  }
};
```

### 3. Улучшено отображение статистики
Обновлен текст статистики для показа более подробной информации:

```typescript
stat: `${stats.totalUsers} пользователей (${stats.activeUsers} активных)`
```

## Используемый API endpoint

Исправление использует существующий API endpoint:
- **GET** `/api/v1/admin/users` - возвращает список всех пользователей с их данными

Этот же endpoint используется на странице "Пользователи" (`/admin/users`), поэтому данные будут согласованными.

## Результат

### До исправления:
- Статистика показывала: "0 пользователей"
- Данные не загружались с сервера

### После исправления:
- Статистика показывает: "X пользователей (Y активных)"
- Данные загружаются с сервера в реальном времени
- Показывается корректное количество пользователей и активных пользователей
- Добавлена обработка ошибок
