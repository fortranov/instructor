# Руководство по администрированию Triplan

## Обзор

Система администрирования Triplan предоставляет возможности управления пользователями, тарифными планами и настройками тренировок.

## Доступ к панели администратора

### Учетные данные администратора
- **Email**: `abramov.yu.v@gmail.com`
- **Пароль**: `admin123` (по умолчанию)

### Вход в систему
1. Перейдите на страницу входа: `/auth/login`
2. Введите учетные данные администратора
3. После входа вы автоматически получите доступ к панели администратора по адресу `/admin`

## Структура панели администратора

### Главная страница (`/admin`)
- Обзор системы
- Быстрые действия
- Статистика пользователей

### Страница "Пользователи" (`/admin/users`)
**Функционал:**
- Просмотр всех зарегистрированных пользователей
- Поиск по имени или email
- Фильтрация по тарифам
- Изменение тарифа пользователя через меню-бургер

**Колонки таблицы:**
- Фамилия
- Имя  
- Email
- Дата регистрации
- Тариф
- Настройки (меню для изменения тарифа)

### Страница "Тарифы" (`/admin/tariffs`)
**Функционал:**
- Настройка функционала тарифных планов
- Управление правами доступа для каждого тарифа

**Тарифные планы:**
1. **Тестовый** - базовый тариф с ограниченным функционалом
2. **Пробный** - промежуточный тариф
3. **Про** - полный функционал

**Настройки тарифов:**
- **Просмотр всего плана**: Пользователи могут видеть все тренировки плана
- **Просмотр двух недель**: Пользователи видят только тренировки на следующие 2 недели

### Страница "Настройки тренировок" (`/admin/workout-settings`)
**Функционал:**
- Редактирование коэффициентов для расчета сложности планов тренировок
- Сброс к значениям по умолчанию

**Группы коэффициентов:**
1. **Недельный километраж** - влияет на сложность в зависимости от текущего уровня пользователя
2. **Комфортный темп** - корректировка сложности по темпу бега
3. **Целевая дистанция** - влияние дистанции соревнования на план
4. **Время подготовки** - корректировка по времени до соревнования

## API Endpoints для администрирования

### Проверка прав
```
GET /api/v1/admin/check-admin
```

### Управление пользователями
```
GET /api/v1/admin/users - получить всех пользователей
PUT /api/v1/admin/users/tariff - изменить тариф пользователя
```

### Управление тарифами
```
GET /api/v1/admin/tariffs - получить все тарифы
PUT /api/v1/admin/tariffs - обновить настройки тарифов
```

### Управление коэффициентами
```
GET /api/v1/admin/workout-coefficients - получить коэффициенты
PUT /api/v1/admin/workout-coefficients - обновить коэффициенты
```

## Влияние настроек на пользователей

### Тарифы
- Изменения тарифов применяются немедленно ко всем пользователям
- Пользователи с тарифом "Просмотр всего плана" видят все тренировки
- Пользователи с тарифом "Просмотр двух недель" видят только ближайшие тренировки

### Коэффициенты тренировок
- Изменения применяются только к **новым** планам тренировок
- Существующие планы не изменяются
- Коэффициенты влияют на расчет сложности плана (0-1000)

- Распределение по тарифам
