## Ключевые изменения

### 1. Макет контейнера
```tsx
// До
<div className="grid grid-cols-1 lg:grid-cols-2 gap-8">

// После  
<div className="space-y-8">
```

### 2. Структура карточек
```
До:  3 карточки (Тариф | Личные данные | План)
После: 2 карточки (Личные данные | Тариф + План)
```

### 3. Внутренняя структура объединенной карточки

```tsx
<Card>
  <CardHeader>План тренировок и тарифы</CardHeader>
  <CardContent>
    {/* Секция 1: Тарифный план */}
    <div className="mb-6 pb-6 border-b">
      <h3>Тарифный план</h3>
      {existingPlan && <PlanInfo />}  {/* 🆕 Инфо о плане здесь */}
      <TariffInfo />
      <ChangeTariffButton />
    </div>
    
    {/* Секция 2: План тренировок */}
    <div>
      <h3>Управление планом тренировок</h3>
      <WizardButton />
      <ManualSettings />
    </div>
  </CardContent>
</Card>
```

## Responsive Design

### Мобильные устройства (< 768px)
- Все карточки располагаются вертикально
- Полная ширина экрана
- Оптимизированные отступы

### Планшеты и десктопы (≥ 768px)
- Вертикальное расположение сохраняется
- Максимальная ширина контейнера: `max-w-4xl`
- Центрирование по горизонтали

## Цветовое оформление

### Информация о существующем плане
```tsx
className="bg-blue-50 border border-blue-200 rounded-lg p-4"
```
- Светло-голубой фон
- Голубая граница
- Выделяет важную информацию о текущем плане

### Разделитель секций
```tsx
className="border-b border-gray-200"
```
- Тонкая серая линия
- Визуально разделяет тариф и план

## Адаптивность

✅ Все элементы корректно отображаются на мобильных устройствах  
✅ Кнопки масштабируются на всю ширину  
✅ Формы остаются читаемыми на маленьких экранах  
✅ Выпадающие списки работают корректно

## Навигация по странице

1. **Личные данные** → верхняя карточка
2. **Тарифный план** → верхняя секция второй карточки
3. **План тренировок** → нижняя секция второй карточки

Логический поток: Пользователь → Тариф → План
