# Улучшение страницы профиля: загрузка данных существующего плана

## Описание изменений

На странице Профиль в блоке "Ручная настройка плана" теперь автоматически загружаются данные пользователя из существующего плана тренировок, если он уже создан.

## Реализованные функции

### 1. Автоматическая загрузка существующего плана

- При открытии страницы профиля автоматически загружается существующий план пользователя
- Если план найден, поля формы заполняются данными из плана:
  - **Уровень сложности** - устанавливается значение из плана
  - **Дата соревнования** - заполняется датой из плана
  - **Тип соревнования** - выбирается соответствующий тип
  - **Дистанция** - заполняется если указана в плане
  - **Предпочтительные дни** - загружаются из профиля пользователя

### 2. Динамическое изменение интерфейса

**Заголовок и описание карточки:**
- Если план существует: показывается информация о текущем плане
- Если плана нет: показывается стандартное описание для создания

**Кнопка мастера планов:**
- Если план существует: "Мастер изменения планов"
- Если плана нет: "Мастер создания планов"

**Кнопка ручной настройки:**
- Если план существует: "Изменить план тренировок"
- Если плана нет: "Создать план тренировок"

**Состояния загрузки:**
- Если план существует: "Обновление плана..."
- Если плана нет: "Создание плана..."

### 3. Отображение информации о существующем плане

В описании карточки "План тренировок" теперь показывается:
- Текущий уровень сложности
- Дата соревнования (в формате DD.MM.YYYY)
- Тип соревнования (с человекочитаемым названием)
- Дистанция (если указана, с правильными единицами измерения)

### 4. Обновление состояния после изменений

- После создания/обновления плана через ручную настройку состояние обновляется
- После создания/обновления плана через мастер состояние также обновляется
- Поля формы автоматически заполняются новыми данными

## Технические детали

### Добавленные состояния:
```typescript
const [existingPlan, setExistingPlan] = useState<TrainingPlan | null>(null);
const [planLoading, setPlanLoading] = useState(false);
```

### Новый useEffect для загрузки плана:
```typescript
useEffect(() => {
  const loadExistingPlan = async () => {
    if (!user?.uin) return;
    
    setPlanLoading(true);
    try {
      const plan = await apiClient.getTrainingPlan(user.uin);
      setExistingPlan(plan);
      
      // Заполняем поля формы данными из существующего плана
      setComplexity(plan.complexity);
      setCompetitionDate(plan.competition_date);
      setCompetitionType(plan.competition_type);
      if (plan.competition_distance) {
        setCompetitionDistance(plan.competition_distance.toString());
      }
    } catch (err) {
      // Если план не найден, это нормально
      setExistingPlan(null);
    } finally {
      setPlanLoading(false);
    }
  };

  if (user?.uin) {
    loadExistingPlan();
  }
}, [user?.uin]);
```

## Пользовательский опыт

### До изменений:
- Пользователь всегда видел пустую форму
- Не было понятно, есть ли уже созданный план
- Приходилось заново вводить все данные для изменения плана

### После изменений:
- Пользователь сразу видит информацию о существующем плане
- Форма автоматически заполнена текущими данными
- Понятно, что происходит создание нового плана или изменение существующего
- Удобно вносить небольшие изменения в существующий план
