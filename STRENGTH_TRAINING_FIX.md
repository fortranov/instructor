# Исправление: Силовые тренировки не отображаются в плане

## Проблема

Пользователи сообщали, что силовые тренировки не отображаются в плане, даже когда настройка `has_strength_training` включена в профиле.

## Причина

Логика генерации планов работает следующим образом:

1. План тренировок создается на основе **текущего** значения `has_strength_training` в базе данных
2. Если пользователь позже изменяет настройку `has_strength_training` в профиле, **план не обновляется автоматически**
3. Силовые тренировки добавляются в план только в фазах `base` и `build` (первые 8 недель подготовки)

### Пример сценария

1. Пользователь создает план с `has_strength_training = 0` (выключено)
2. Пользователь включает настройку `has_strength_training = 1` в профиле
3. План остается без силовых тренировок, так как он не пересоздается автоматически

## Исправление

### Что было сделано

1. **Добавлено визуальное предупреждение** в `frontend/src/app/profile/page.tsx`:
   - Когда пользователь изменяет настройку `has_strength_training` и у него есть существующий план, отображается предупреждение: "⚠️ Для применения изменений нужно пересоздать план"
   - Аналогичное предупреждение добавлено для изменения предпочтительных дней тренировок

2. **Проверена корректность работы генератора планов**:
   - При `has_strength_training = 1` план создает силовые тренировки корректно
   - Силовые тренировки добавляются 1 раз в неделю в фазах `base` и `build`
   - Длительность силовой тренировки: 50 минут
   - Тип: `SportType.STRENGTH`, `WorkoutType.RECOVERY`

### Файлы изменены

- `frontend/src/app/profile/page.tsx` - добавлены предупреждения для пользователей

## Инструкция для пользователей

Чтобы добавить силовые тренировки в существующий план:

1. Откройте страницу **Профиль**
2. В разделе "Настройки плана" включите опцию **"Включить силовые тренировки в план"**
3. Нажмите кнопку **"Изменить план тренировок"** (или **"Создать план тренировок"**)
4. План будет пересоздан с учетом силовых тренировок

## Технические детали

### Где добавляются силовые тренировки

- **Файл**: `backend/plan_generator.py`
- **Метод**: `_generate_workouts()`, строки 126-132
- **Условия**:
  - `has_strength_training = 1`
  - Фаза тренировки: `base` или `build` (первые 8 недель)
  - 1 силовая тренировка в неделю
  - Размещается в свободный предпочтительный день недели

### Как проверить, что силовые тренировки создаются

```python
# В backend директории
python -c "
from database import SessionLocal, Workout, SportType, User
db = SessionLocal()

# Найти пользователя
user = db.query(User).filter(User.email == 'your@email.com').first()
print(f'has_strength_training: {user.has_strength_training}')

# Посчитать силовые тренировки
from database import TrainingPlan
plan = db.query(TrainingPlan).filter(TrainingPlan.user_id == user.id).first()
strength_count = db.query(Workout).filter(
    Workout.plan_id == plan.id,
    Workout.sport_type == SportType.STRENGTH
).count()
print(f'Силовых тренировок в плане: {strength_count}')

db.close()
"
```
