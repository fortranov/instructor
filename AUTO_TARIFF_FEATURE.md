# Автоматическое назначение тестового тарифа

## Описание

При регистрации нового пользователя ему автоматически назначается **тестовый тариф "Тестовый"**.

## Что изменено

✅ Модифицирована функция `create_user` в файле `backend/auth.py`  
✅ При создании пользователя автоматически ищется и назначается тестовый тариф  
✅ Создана документация в `backend/AUTO_TARIFF_ASSIGNMENT.md`

## Параметры тестового тарифа

- **Название:** Тестовый
- **Тип:** test
- **Просмотр всего плана:** Нет (только 2 недели)
- **Просмотр двух недель:** Да

## Как это работает

1. Пользователь регистрируется через `/api/v1/auth/register`
2. Функция `create_user` создаёт нового пользователя
3. В процессе создания автоматически находится тестовый тариф
4. Пользователю присваивается `tariff_id` тестового тарифа
5. Пользователь может сразу использовать возможности тестового тарифа

## Инициализация

Убедитесь, что тарифы созданы в базе данных:

```bash
python backend/init_admin_data.py
```

## Проверка

Проверить назначение тарифа можно через API:

```bash
# 1. Зарегистрировать пользователя
POST /api/v1/auth/register
{
  "email": "user@example.com",
  "password": "password123"
}

# 2. Авторизоваться
POST /api/v1/auth/login
{
  "email": "user@example.com",
  "password": "password123"
}

# 3. Проверить тариф
GET /api/v1/user/tariff
Authorization: Bearer <token>
```
