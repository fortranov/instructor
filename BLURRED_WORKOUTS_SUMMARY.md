# Сводка: Замыленные карточки тренировок

## ✅ Выполненная задача

Создана система отображения тренировок с ограничением по тарифу:
- **Доступные тренировки** - отображаются стандартно
- **Недоступные тренировки** - отображаются в замыленном виде с иконкой замка

## 📋 Что было сделано

### 1. Создан компонент `BlurredWorkoutCard`
**Файл:** `frontend/src/components/blurred-workout-card.tsx`

Визуальные эффекты:
- 🔒 Иконка замка по центру
- 🌫️ Blur эффект (2px)
- 👻 Полупрозрачность (opacity: 0.5)
- 🚫 Отключенное взаимодействие (pointer-events: none)
- 🎨 Серый фон (#f9fafb)

### 2. Обновлен компонент `Calendar`
**Файл:** `frontend/src/components/calendar.tsx`

Добавлено:
- Проп `userTariff?: UserTariffResponse | null`
- Функция `isWorkoutAccessible(workoutDate: string): boolean`
- Логика рендеринга обычной или замыленной карточки

### 3. Обновлена страница `Plan`
**Файл:** `frontend/src/app/plan/page.tsx`

Добавлено:
- State для хранения тарифа пользователя

## 🧪 Тестирование

### Как проверить:

1. **Создайте пользователя с тестовым тарифом:**
   - Зарегистрируйтесь
   - Создайте план тренировок на 2-3 месяца
   - Откройте страницу плана
   - **Ожидаем:** Первые 2 недели четкие, остальные замылены

2. **Пробный тариф (через админку):**
   - Смените тариф на `trial`
   - **Ожидаем:** Первые 3 недели четкие, остальные замылены

3. **Про тариф (через админку):**
   - Смените тариф на `pro`
   - **Ожидаем:** Все тренировки четкие
