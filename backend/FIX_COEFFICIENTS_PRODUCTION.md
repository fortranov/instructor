# Исправление ошибки 500 с коэффициентами тренировок

## Проблема
При запросе коэффициентов тренировок возникает ошибка 500:
```
GET /api/v1/admin/workout-coefficients 500 (Internal Server Error)
```

## Причина
Таблица `workout_coefficients` не существует в продакшене или не содержит данных.

## Решение

### Вариант 1: Запуск скрипта исправления
```bash
# В контейнере бэкенда
python fix_coefficients.py
```

### Вариант 2: Полная переинициализация БД
```bash
# В контейнере бэкенда
python init_production_db.py
```

### Вариант 3: Через Docker Compose
```bash
# На сервере
docker-compose exec backend python fix_coefficients.py
```

## Проверка результата
После выполнения скрипта должно появиться сообщение:
```
🎉 Исправление завершено успешно!
```

Затем проверьте работу админки - коэффициенты должны загружаться без ошибок.

## Что делает скрипт
1. Создает таблицу `workout_coefficients`, если её нет
2. Добавляет коэффициенты по умолчанию
3. Проверяет существующие коэффициенты

## Коэффициенты по умолчанию
- Недельный километраж: 10-300
- Темп бега: 20-300  
- Целевая дистанция: 50-250
- Время подготовки: 100 базовых единиц, 16 недель оптимально
