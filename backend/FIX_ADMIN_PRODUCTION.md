# Исправление проблем админки на продакшене

## Проблемы
1. **Ошибка 500 при обновлении тарифа пользователя:**
   ```
   PUT /api/v1/admin/users/tariff 500 (Internal Server Error)
   ```

2. **Ошибка 500 при загрузке коэффициентов:**
   ```
   GET /api/v1/admin/workout-coefficients 500 (Internal Server Error)
   ```

## Причины
- Отсутствует колонка `tariff_id` в таблице `users`
- Отсутствует таблица `tariffs` или нет тарифов
- Отсутствует таблица `workout_coefficients` или нет коэффициентов
- Нет пользователя-администратора

## Решение

### Вариант 1: Универсальный скрипт (рекомендуется)
```bash
# В контейнере бэкенда
docker-compose exec backend python fix_admin_issues.py
```

### Вариант 2: Отдельные скрипты
```bash
# Исправить тарифы
docker-compose exec backend python fix_tariffs.py

# Исправить коэффициенты  
docker-compose exec backend python fix_coefficients.py

# Создать администратора
docker-compose exec backend python init_admin_data.py
```

### Вариант 3: Полная переинициализация
```bash
# Полная инициализация БД
docker-compose exec backend python init_production_db.py
```

## Что делает универсальный скрипт

1. **Создает все таблицы**, если их нет
2. **Добавляет колонку `tariff_id`** в таблицу `users`
3. **Создает тарифы по умолчанию:**
   - Тестовый (только 2 недели)
   - Пробный (только 2 недели)  
   - Про (весь план)
4. **Назначает тестовый тариф** пользователям без тарифа
5. **Создает коэффициенты тренировок** по умолчанию
6. **Создает администратора:**
   - Email: `abramov.yu.v@gmail.com`
   - Пароль: `admin123`
