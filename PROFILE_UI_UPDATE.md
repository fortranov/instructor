# Обновление UI страницы профиля

## Описание изменений

Объединены блоки **"Тарифный план"** и **"План тренировок"** в один `Card` на странице профиля.

## Что изменено

### Файл: `frontend/src/app/profile/page.tsx`

#### До изменений:
- Страница содержала 3 отдельных карточки в сетке `lg:grid-cols-2`:
  1. Тарифный план (левая колонка)
  2. Личные данные (правая колонка)
  3. План тренировок (левая колонка)

#### После изменений:
- Страница теперь содержит 2 карточки в вертикальном макете:
  1. **Личные данные** - отдельная карточка
  2. **План тренировок и тарифы** - объединенная карточка, содержащая:
     - Секцию тарифного плана (верхняя часть)
     - Разделитель
     - Секцию плана тренировок (нижняя часть)

## Структура объединенной карточки

```tsx
<Card>
  <CardHeader>
    <CardTitle>План тренировок и тарифы</CardTitle>
    <CardDescription>
      Управление вашим планом тренировок и тарифным планом
    </CardDescription>
  </CardHeader>
  <CardContent>
    {/* Секция тарифного плана */}
    <div className="mb-6 pb-6 border-b border-gray-200">
      <h3>Тарифный план</h3>
      {/* Информация о существующем плане (если есть) */}
      {/* Текущий тариф */}
      {/* Кнопка смены/продления тарифа */}
    </div>

    {/* Секция плана тренировок */}
    <div>
      <h3>Управление планом тренировок</h3>
      {/* Кнопка мастера планов */}
      {/* Выпадающая ручная настройка */}
    </div>
  </CardContent>
</Card>
```

## Преимущества изменений

✅ **Лучшая организация:** Связанные функции (план тренировок и тариф) теперь находятся в одном месте  
✅ **Улучшенная читаемость:** Вертикальный макет более естественен для чтения  
✅ **Логическая группировка:** Тариф и план тренировок логически связаны - тариф определяет, что пользователь может видеть в плане  
✅ **Меньше визуального шума:** Уменьшено количество отдельных карточек на странице

## Визуальные изменения

### Информация о существующем плане
Если у пользователя уже есть план, его информация отображается в выделенном блоке в секции тарифного плана:

```
┌─────────────────────────────────────────┐
│ Тарифный план                           │
│ ┌─────────────────────────────────────┐ │
│ │ Сложность: 500                      │ │
│ │ Дата соревнования: 01.12.2024      │ │
│ │ Тип соревнования: Полумарафон      │ │
│ └─────────────────────────────────────┘ │
│ Текущий тариф: Тестовый                │
│ [Сменить тарифный план]                │
└─────────────────────────────────────────┘
```
